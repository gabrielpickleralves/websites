# explainer-video

An Agent Skill for Claude Code / Codex: 30-60s motion-graphics explainers and demo videos made entirely in code. Remotion + React for the picture, a numpy synth for the music and sound design, one `timeline.json` driving both, rendered to mp4 on a laptop.

`reference/` is a finished 40s video, "How a coding agent works".

Install:

```bash
git clone https://github.com/arthurkatcher/explainer-video ~/.claude/skills/explainer-video
```

Then ask your agent for "an explainer video about X".
