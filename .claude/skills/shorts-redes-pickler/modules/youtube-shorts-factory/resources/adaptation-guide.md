# 각색 가이드 & 사례 모음

## 각색의 원칙

### 30% 규칙

저작권 침해 없이 레퍼런스 영상의 성공 공식을 활용하려면 최소 30% 이상 변경이 필요.

### 변경 가능 요소 (외피)

| 요소 | 설명 | 변경 용이도 |
|------|------|-----------|
| 인물 관계 | 부부→부모자식, 친구→동료 | ★★★★★ |
| 장소/배경 | 집→사무실, 도시→시골 | ★★★★☆ |
| 핵심 소품 | 편지→메모, 꽃→음식 | ★★★★☆ |
| 시대/계절 | 현대→과거, 여름→겨울 | ★★★☆☆ |
| Payoff 장치 | 메시지 전달 방식 변경 | ★★★☆☆ |

### 보존해야 할 요소 (뼈대)

| 요소 | 설명 |
|------|------|
| 감정 곡선 | Hook → 긴장 → 행동 → 반전 순서 |
| Silent Hero 패턴 | 대사 없이 행동으로 보여주기 |
| Open Loop 개수 | 원본과 동일한 수의 궁금증 장치 |
| Payoff 타이밍 | 마지막 3~5초에 반전 배치 |
| 페이싱 | 컷 길이와 템포 |

## 각색 패턴 라이브러리

### 패턴 1: 관계축 전환

```
부부 → 부모자식
부부 → 조부모-손주
연인 → 오래된 친구
상사-부하 → 선배-후배
```

### 패턴 2: 공간축 전환

```
집 → 사무실 (야근하는 동료를 위해)
집 → 병원 (환자를 위해)
집 → 군대 (전우를 위해)
도시 → 시골 (귀향)
```

### 패턴 3: 시간축 전환

```
현재 → 과거 회상 (어린 시절)
일상 → 특별한 날 (생일, 기일)
평일 → 명절 (추석, 설)
```

### 패턴 4: Payoff 장치 교체

```
편지 → 냉장고 메모
직접 말함 → SNS 메시지
선물 → 조용히 해놓은 행동 발견
눈물 → 미소 (역전 감정)
```

## 한국적 디테일 소품 라이브러리

감정별로 사용할 수 있는 한국 가정의 소품:

### 외로움/그리움
- 빈 냉장고 (혼자 사는 노인)
- 주간 약통 (빈칸 있는)
- 바래진 가족사진
- 작은 TV 앞 혼자 놓인 밥상

### 사랑/돌봄
- 된장찌개/김치찌개 끓이는 장면
- 이불 덮어주기
- 약 챙겨놓기
- 반찬통 채워놓기

### 반전/감동
- 냉장고 메모 ("밥 먹었어. 고마워.")
- 현관문 앞 놓인 반찬 봉지
- 통장에 찍힌 이체 기록
- 오래된 일기장 한 줄

### 시간의 흐름
- 달력의 X표시
- 닳은 슬리퍼
- 색 바랜 커튼
- 벽시계의 째깍소리
